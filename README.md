# kabuka — 日本株 株価予測・売買シグナル基盤

日本株のファンダメンタルズ・テクニカル・センチメント情報を自動で収集・分析し、
**株価予測ダッシュボード**と**売買シグナル**を提供するアプリケーション。

## ⚠️ 重要な免責事項

- 本プロジェクトは**投資助言・金融商品取引業に該当するサービスではありません**。個人の投資判断を補助する研究・分析ツールです。
- 予測やシグナルは**将来の利益を保証しません**。すべての投資判断と結果は利用者自身の責任です。
- **「年間利益20%」は目標であって約束ではありません。** プロの運用でも長期で年率20%を安定維持するのは極めて困難です。
  本プロジェクトでは20%を「狙う目標」として置き、**実際の期待リターンとリスク（最大ドローダウン等）はバックテストで数値検証**します。
- ニュース・データ取得は各サービスの利用規約を遵守します（無断スクレイピングは行わない）。

## ゴール

1. **株価予測ダッシュボード** — 価格・出来高・テクニカル指標・財務・ニュースを一画面で可視化
2. **売買シグナル提示** — 中長期を主戦場に、デイトレ向けの短期シグナルも提供（売買は当面ユーザー自身が実行）
3. **自動考察** — 以下3カテゴリの情報を自動収集して分析
   - ファンダメンタルズ（業績・財務・マクロ・バリュエーション）
   - テクニカル（価格・出来高・トレンド系/オシレーター系指標）
   - センチメント／ニュース（報道・市場心理・機関投資家動向）
4. **（将来）モバイルアプリ** — iPhone / Android
5. **（将来・要慎重）自動売買** — 証券会社API連携

## 技術スタック

- **バックエンド**: Python 3.12 / FastAPI / SQLAlchemy(SQLModel)
- **データ取得**: J-Quants API（JPX公式）, yfinance（補助）, 各社IR・ニュースRSS
- **DB**: PostgreSQL（+ TimescaleDB） / 開発初期は SQLite
- **ジョブ**: APScheduler（→ 規模に応じ Celery）
- **分析・予測**: pandas, ta, scikit-learn, LightGBM, （センチメントにLLM）
- **検証**: 自前バックテスト基盤（シャープレシオ・最大DD・勝率・期待リターン）
- **フロント**: React/TypeScript（Web: Next.js / 将来モバイル: React Native + Expo / モノレポ構成）
