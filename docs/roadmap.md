## メイン機能 — フォワード・ペーパートレード（アプリの目的）
予測に基づき短期・中期・長期の買い候補と売りタイミングを提示し、仮想資金で実時間検証する。
**この予測精度を高めることがアプリの目的**。

- [x] 期間別 推奨エンジン（`app/signals/recommend.py`）: 長期=value+quality(信頼度高) / 中期=value傾斜(高・本命) / 短期=reversal等(低・実験的)。透明な売りルール（損切り/利確/順位脱落/期間切れ）。
- [x] 仮想ポートフォリオ（`app/signals/portfolio.py`）: J-Quants最新終値で約定・評価、売りシグナル自動判定。
- [x] API（/api/recommendations, /api/paper/*）＋ 画面（期間タブ・買い/売りボタン・損益表示）。
- [x] ブラウザ投資シミュレーター（過去データでの条件別検証）。

### 精度向上ロードマップ（最優先）
- [ ] **データ日次リフレッシュ**（APScheduler）: 推奨を現在データで計算（今はキャッシュ2024-12と執行ライブ価格に乖離）。
- [ ] **フォワード成績の記録・学習**: 各推奨の将来結果をログ化→実OOS的中率/ICを継続測定。
- [ ] ウォークフォワードでファクター重み再検証（レジーム変化対応）／売りルールの履歴最適化。
- [ ] リスク管理（ボラ建玉サイズ・セクター上限・ドローダウン制御）。
- [ ] 短期モデルの専用バックテスト確立（確立まで「実験的」表示を維持）。

**完了の定義**: 無料データで対TOPIXαの有無に一次判断がつく（Go/No-Go の材料が出る）。
